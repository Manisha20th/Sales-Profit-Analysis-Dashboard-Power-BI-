# Sales & Profit Analysis Dashboard (Power BI)

This project features an interactive Power BI dashboard created to analyze sales performance, profitability, and customer behavior based on transactional data. The analysis provides key insights into product performance, regional sales drivers, and critical profitability issues.
⭐ Key Highlights & Skills Demonstrated
End-to-End Data Analysis: Full project lifecycle from raw CSV data to final interactive dashboard.
Data Modeling: Established a robust Star Schema with one-to-many relationships (Sales <-> Products, Sales <-> Customers).
Data Transformation (Power Query M): Cleaned data types and engineered crucial calculated columns (Revenue, COGS, Profit) at the source level.
DAX Measures: Developed key business metrics (Total Revenue, Total Profit, Average Order Value) using DAX.Interactive Visualizations: Created diverse charts (Bar, Line, Donut, Matrix) and implemented slicers for dynamic filtering.
